Skills from the engineering-lifecycle plugin, and when each applies: changing-code (any change to existing code: fixes, debugging, incidents, refactors, upgrades, tests); handling-artifacts (files a task creates or ships: scratch scripts, dumps, screenshots, exports; cleanup, redaction, packaging, repo size); merging-safely (merging branches, resolving conflicts, checking a fix landed); reviewing-code (any opinion on code, a diff or a PR); shaping-designs (how to build or change something: designs, APIs, data, migrations, requirements, X or Y). When one covers the task, load it before answering, even if the task looks simple.
